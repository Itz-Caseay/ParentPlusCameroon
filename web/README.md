# Parent+ Cameroon — Prototype

This prototype is based on the Parent+ Cameroon concept submitted by NurtureTech Cameroon.

## Included prototype flows

- Landing page
- Parent registration/profile
- Child age-group selection
- Digital Parenting Academy
- 20 sample micro-learning modules
- Lesson + quick quiz
- Progress dashboard
- Parenting support topics
- Community/resources area
- Feedback form
- English/French language toggle foundation
- Responsive/mobile-first interface
- Express API scaffold for future database integration

## Run locally

1. Install Node.js.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm start
```

4. Open `http://localhost:3000`
